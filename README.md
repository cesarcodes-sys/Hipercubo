# Hipercubo

Simulación gráfica de rutas dentro de un hipercubo utilizando Python, Turtle y Tkinter.

El proyecto permite visualizar recorridos entre nodos mediante operaciones XOR y representación binaria, mostrando de forma dinámica las conexiones y trayectorias dentro de la estructura del hipercubo.

---

## Características

- Representación gráfica de un hipercubo
- Visualización de nodos y conexiones
- Simulación de rutas entre vértices
- Cálculo de rutas mediante operaciones XOR
- Interfaz gráfica interactiva
- Validación de entradas
- Generación dinámica de recorridos

---

## Tecnologías utilizadas

- Python
- Tkinter
- Turtle Graphics
- Threading

---

## Ejecución

Clona el repositorio:

```bash
git clone https://github.com/cesarcodes-sys/Hipercubo.git
```

Entra al proyecto:

```bash
cd Hipercubo
```

Ejecuta:

```bash
python Hipercubo2.py
```
